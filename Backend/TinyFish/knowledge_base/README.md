# Industrial Safety Knowledge Base

## Important Notice & Integrity Disclaimer
The documents in this directory are **curated reference extracts** compiled for explainable RAG grounding and statutory baseline alignment.

They contain relevant standard clauses, safety definitions, and operating guidelines extracted from standard industry publications:
- **IOGP Report 459**: Life-Saving Rules reference clauses and guidance.
- **OISD Standard 105**: Work Permit System and Confined Space Entry requirements.
- **OISD-GDN-112**: Hydrogen Sulfide (H2S) Operational Safety Guidelines reference extracts.
- **Operating Procedures**: Separator Vessel Entry & Sludge Removal SOP reference extract.

## Deployment Requirements
1. **Reference Extracts**: These files are reference extracts for deterministic, explainable RAG grounding.
2. **Authoritative Extension**: In an operational enterprise deployment, this knowledge base can be augmented with verified full-text statutory manuals, internal SOP PDFs, and official corporate guidelines.
3. **Zero Fabrication Policy**: All internal evidence retrieved by the RAG pipeline is drawn strictly from these verified reference files without simulated or fabricated citations.
